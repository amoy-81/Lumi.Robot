## Plan Conventions
Plans stored here follow the `superpowers:writing-plans` format:
- Vertical, testable slices aligned with [LUMI_PROJECT_BRIEF.md](file:///C:/Users/NIAVARAN/Downloads/LUMI_PROJECT_BRIEF.md) §10 (foundation & contracts → fake-driven controller → face & audio → offline speech → predefined conversation/context → integrated desktop MVP → hardware validation).
- Explicit `Files: Create / Modify / Test` declarations.
- Exact method signatures, contracts, and TDD verification commands (`pytest`).
- Checkbox tracking (`- [ ]`) for execution.

When the feature specifications are approved, phased implementation plans (e.g., `YYYY-MM-DD-feat-00-foundation.md`) will be generated here.
